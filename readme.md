# Project: Python-Journal

### Description: 
Python-Journal is an app coded in python, and can be used to create and store encrypted journals entries, quickly, simply, and locally<br> 

### How the important parts work:
1.When creating an entry, it will ask you to enter a key in addition to the actual text for the journal entry<br> 
2.It will run the journal entry text through a Vigenère cipher which will return text in a very hard-to-break code<br> 
3.When accessing an entry at a later point, it will ask you for a key<br> 
4.When you enter the key, it will run the encrypted entry (that it has stored locally) back through the vigenere cipher using the given key<br> 
5.Regardless of whether the right key was entered, it will show you the output from the decryption (if you gave it the right key, it will return the 
&emsp; perfectly unencrypted journal entry you made. if you gave it the wrong key, it will return gibberish)
